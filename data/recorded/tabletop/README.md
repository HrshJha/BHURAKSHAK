# Tabletop records

This folder contains a seeded stand-in for sensor readings from a physical tabletop rig. It was generated by `scripts/generate_tabletop_dataset.py` with seed 42. The rig campaign has not been run.

- `trial_metadata.csv` records each test condition and target displacement.
- `processed_windowed_dataset.csv` contains sensor features and reference displacement.
- `raw_sensor_log.csv` can be regenerated with the command below.

```bash
.venv/bin/python scripts/generate_tabletop_dataset.py data/recorded/tabletop
```
